# Network Route Simulator

Консольная программа на Python для моделирования сети роутеров и поиска маршрутов между ними.

Программа позволяет работать с ориентированным графом, добавлять и удалять соединения, искать маршруты с помощью BFS и алгоритма Дейкстры, а также сохранять граф в JSON-файл.

## Возможности

- Показ структуры графа
- Поиск маршрута с помощью BFS
- Поиск самого быстрого маршрута с помощью алгоритма Дейкстры
- Сравнение BFS и алгоритма Дейкстры
- Проверка прямого соединения между роутерами
- Просмотр соседей выбранного роутера
- Добавление нового соединения
- Удаление соединения
- Удаление роутера вместе со всеми его связями
- Сохранение графа в JSON
- Загрузка графа из JSON

## Структура проекта

```text
network_route_simulator/
│
├── main.py
├── algorithms.py
├── graph_utils.py
├── storage.py
└── README.md



Требования
Для запуска нужен Python 3.
Проверить версию Python можно командой:
python3 --version


Запуск
1.	Открой терминал в папке проекта.
2.	Запусти программу:
python3 main.py

После запуска появится меню программы.
Пример графа
По умолчанию используется такой граф:
A -> B (10 мс, 100 Мбит/с)
A -> C (20 мс, 80 Мбит/с)
B -> D (15 мс, 70 Мбит/с)
C -> D (5 мс, 60 Мбит/с)

Например, маршрут из  A  в  D  может выглядеть так:A -> B -> D
A -> C -> D
Алгоритм BFS выбирает маршрут с меньшим количеством переходов, а алгоритм Дейкстры ищет путь с минимальной суммарной задержкой.
Пункты меню
1. Показать граф
2. Найти маршрут
3. Проверить прямое соединение
4. Показать соседей узла
5. Найти самый быстрый маршрут
6. Сравнить BFS и Дейкстру
7. Добавить соединение
8. Удалить соединение
9. Удалить роутер
10. Сохранить граф в файл
11. Загрузить граф из файла
0. Выход


Сохранение графа
Чтобы сохранить текущую сеть:
1.	Выбери пункт  10 .
2.	Введи имя файла, например:
graph.json
Чтобы загрузить сохраненную сеть:
1.	Выбери пункт  11 .
2.	Введи имя файла:
graph.json


Используемые алгоритмы
BFS
BFS (Breadth-First Search) — алгоритм поиска в ширину. В проекте он находит маршрут с минимальным количеством переходов между роутерами.
Алгоритм Дейкстры
Алгоритм Дейкстры ищет путь с минимальной общей задержкой. Для каждого соединения учитывается задержка в миллисекундах.

## Как создать файл

В VS Code:

1. Нажми правой кнопкой по папке проекта.
2. Выбери **New File**.
3. Назови файл `README.md`.
4. Вставь текст выше.
5. Сохрани: `Cmd + S`.

Расширение `.md` означает Markdown: это простой формат, в котором `#` создает заголовок, `-` — список, а тройные обратные кавычки создают блок кода.
